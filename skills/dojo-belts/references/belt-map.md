# Belt map

Belts are consecutive. A failed kata blocks every belt above it. There is no percentage, health score, or AI IQ.

```text
welcome     enter-the-dojo
start       operator-profile
stay        memory-loop
improve     superninja
full OS     every suite in verify-os.js
```

| Belt | Earn when these katas PASS |
|------|----------------------------|
| white | `enter-the-dojo` |
| yellow | white + `operator-profile` |
| green | yellow + `memory-loop` |
| brown | green + `superninja` |
| black | **all** `verify-os.js` suites |

Door B extras (`inspect-os`, `connector-map`, `career-loop`, `factory-intake`) are required for **black**, not for brown.

`none` means the welcome kata has not passed yet.
