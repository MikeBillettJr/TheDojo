# Spec card (before any write)

Show this to the operator and wait for named approve. Do not create `skills/<name>/` first.

```text
Problem:
Done when:
Out of scope:
Constraints:
Patterns to mirror: (existing skill paths)
Files to add/change:
Acceptance tests: (3-7 binary checks)
Eval cases to add:
Off-limits:
Risk / blast radius:
```

After approve: stage the candidate `SKILL.md` outside `skills/`, run `skill-gate.js`, then copy live only if the report PASSes and they name that adopt.
