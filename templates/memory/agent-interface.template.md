# Agent interface

How agents should communicate with you. Update via `operator-profile`.

## Tone

- **Default:** {DIRECT_FRIENDLY_BLUNT}
- **When tired:** {SHORTER_LESS_TEACHING}
- **When building:** {MORE_DETAIL_OK}

## Pace

- Lead with outcome; teach only when it changes a decision.
- One focused question when blocked — not a questionnaire.

## Output

- Complete sentences; no telegraphic shorthand unless asked.
- Separate facts, recommendations, and assumptions.
